## 🌟 Overview & High-Search Use Cases

**FocusFlow** is built for everyday focus, daily routines, deep work, and wellness tracking:
* 🎯 **Daily Goals & Morning Kickoff:** Fast intention setting with a dropdown of previously used goals.
* ⚡ **Fullscreen Zen Focus Cockpit HUD:** Real-time session progress, 4-card daily metrics, quick hydration sip (+250ml), and live streak counter.
* 🎧 **Procedural Ambient Soundscapes:** Continuous Rain, Cafe, Forest, Ocean, and 432Hz binaural beats with sleep timer.
* 🔕 **Loud Multi-Tone Alarm:** Bypasses phone silent mode with 1-tap dismissal.
* 💧 **Hydration & 20-20-20 Eye Rest:** Smart wellness breaks preventing digital eye fatigue.
* 📋 **Task Flow & Category Filters:** Checklists with high/medium/low priorities and estimate tags.
* 💰 **Everyday Toolbox:** Instant auto-saving scratchpad, daily expense budgeter, and tip/split calculator.
* 🌙 **Evening Reflection & 7-Day Consistency Pulse:** Daily win logger and streak tracker.

## 🛠️ Build & Run Commands

```bash
# Run locally in browser
npx serve .

# Sync web assets to Android
npx cap copy android

# Open Android Studio Project
npx cap open android

# Build production Release APK / AAB
cd android && ./gradlew bundleRelease
```
